# 03 · 后端工程结构与配置

> 技术栈：Kotlin 2.x · JDK 21 · Gradle 9 (Kotlin DSL + Version Catalog) · Spring Boot 4.1.1 · Spring WebFlux · Spring Data Jdbc · PostgreSQL

### 模块职责与依赖规则

| 模块 | 职责 | 允许依赖 |
|---|---|---|
| `agri-gateway` | 只做路由转发、JWT 解析、内部头剥离、限流 | common-* |
| `agri-auth` | 登录、令牌签发/续期、租户切换、权限快照计算 | common-* + upms-api |
| `agri-upms` | 系统级权限主数据（用户/租户/角色/权限/数据范围策略） | common-* |
| `agri-app-trade` / `agri-app-agro` | 纯业务域，不含任何权限模型 | common-* + upms-api（只读） |
| `*-api` | 只有接口与 DTO，供其他服务依赖 | common-core |

> **铁律**：业务域服务（trade/agro）**禁止直接查询 `sys` schema 的表**，只能通过 `upms-api` 的 Facade 接口。否则权限模型的任何调整都会扩散到所有业务服务。

### 分层依赖方向（严格单向）

```
interfaces → application → domain ← infrastructure
                              ↑
                      (infrastructure 实现 domain 定义的端口)
```

- `domain` **不依赖** Spring、MyBatis、Jackson；
- `infrastructure` 依赖 `domain`（实现其接口），`domain` 不反向依赖 `infrastructure`（依赖倒置）；
- 跨层数据用 Assembler/Converter 转换，禁止把 PO 直接返回给前端。

### 4.2 上下文载体：`UserContext` + 协程桥接

> 这是 WebFlux + MyBatis 混合模型下**最关键的一块**。
> 请求在 Netty EventLoop 上，MyBatis 拦截器在 IO 线程池上，两端都要能读到同一个上下文；
> 而 MyBatis 拦截器是同步阻塞代码，只能靠 ThreadLocal。

```kotlin
package com.agri.common.security.context

/**
 * 一次请求内的权限上下文。不可变对象，跨线程只读。
 */
data class UserContext(
    val userId: Long,
    val userName: String,
    val userKind: UserKind,          // NORMAL / SUPER_ADMIN / SYSTEM
    val memberId: Long?,             // 超管为 null
    val tenantId: Long?,             // 超管为 null
    val tenantTypeCode: String?,
    val appId: Long,
    val appCode: String,
    val orgId: Long?,
    val orgTreeIds: Set<Long>,       // ORG_TREE 数据范围用，登录时一次性展开
    val isTenantAdmin: Boolean,
    val permissionCodes: Set<String>,
    val dataScopes: Map<String, DataScopeRule>,   // objectCode -> 生效规则
) {
    val isSuperAdmin: Boolean get() = userKind == UserKind.SUPER_ADMIN

    fun hasPermission(code: String): Boolean = isSuperAdmin || isTenantAdmin || code in permissionCodes

    fun scopeOf(objectCode: String): DataScopeRule = dataScopes[objectCode]
        ?: DataScopeRule(scopeType = ScopeType.TENANT_ALL)
}

enum class UserKind { NORMAL, SUPER_ADMIN, SYSTEM }

data class DataScopeRule(
    val objectCode: String,
    val scopeType: ScopeType,
    val expression: String? = null,     // CUSTOM_SQL 的 where 片段
    val params: Map<String, Any?> = emptyMap(),
)

enum class ScopeType {
    GLOBAL, TENANT_ALL, ORG_TREE, ORG_SELF, MEMBER_TEAM, MEMBER_SELF, CUSTOM_SQL, DENY_ALL
}
```

```kotlin
package com.agri.common.security.context

import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import java.util.concurrent.ConcurrentHashMap
import kotlin.coroutines.CoroutineContext

/**
 * ThreadLocal 持有者：仅供 MyBatis 拦截器（IO 线程、同步代码）读取。
 * 业务代码一律通过 UserContextElement 拿上下文，不要直接用这里。
 */
object UserContextHolder {
    private val TL = ThreadLocal<UserContext>()

    fun set(ctx: UserContext) = TL.set(ctx)
    fun get(): UserContext? = TL.get()
    fun clear() = TL.remove()
}

/**
 * 协程上下文元素：随协程挂起/恢复自动跨线程传播。
 */
data class UserContextElement(val context: UserContext) : CoroutineContext.Element {
    companion object Key : CoroutineContext.Key<UserContextElement>
    override val key: CoroutineContext.Key<*> = Key
}

/**
 * 阻塞 JDBC 执行的专用调度器。
 * 并发度与 HikariCP maximum-pool-size 对齐，避免"协程抢到线程却等不到连接"。
 */
object JdbcDispatcher {
    private val cache = ConcurrentHashMap<Int, CoroutineContext>()

    fun io(concurrency: Int): CoroutineContext =
        cache.computeIfAbsent(concurrency) {
            Dispatchers.IO.limitedParallelism(it)
        }
}

/**
 * 在 IO 线程执行阻塞的 MyBatis 调用，并把上下文刷进该线程的 ThreadLocal，
 * 使 MyBatis 拦截器可读。离开时强制清理，防止线程复用造成上下文串号。
 */
suspend fun <T> withJdbcContext(ctx: UserContext, concurrency: Int, block: suspend () -> T): T =
    withContext(JdbcDispatcher.io(concurrency)) {
        UserContextHolder.set(ctx)
        try {
            block()
        } finally {
            UserContextHolder.clear()   // 必须 finally，异常路径也不能残留
        }
    }
```

### 4.4 租户隔离拦截器（强制注入 `tenant_id`）

```kotlin
package com.agri.common.mybatis.interceptor

import com.agri.common.security.context.ScopeType
import com.agri.common.security.context.UserContextHolder
import net.sf.jsqlparser.expression.LongValue
import net.sf.jsqlparser.expression.operators.conditional.AndExpression
import net.sf.jsqlparser.expression.operators.relational.EqualsTo
import net.sf.jsqlparser.parser.CCJSqlParserUtil
import net.sf.jsqlparser.statement.select.PlainSelect
import net.sf.jsqlparser.statement.select.Select
import net.sf.jsqlparser.statement.update.Update
import org.apache.ibatis.executor.Executor
import org.apache.ibatis.mapping.BoundSql
import org.apache.ibatis.mapping.MappedStatement
import org.apache.ibatis.plugin.*
import org.apache.ibatis.session.ResultHandler
import org.apache.ibatis.session.RowBounds
import java.sql.Statement

/**
 * 多租户隔离拦截器（兜底防线）。
 *
 * 规则：
 *  1. 若上下文是超管且无 tenantId → 不注入（超管跨租户）；
 *  2. biz schema 下的表一律注入 tenant_id 条件（白名单外的系统表跳过）；
 *  3. 幂等：SQL 中若已显式带该表的 tenant 条件，则不重复注入；
 *  4. 无法解析的 SQL 直接抛异常，宁可失败也不放过（fail-fast）。
 *
 * 拦截 Executor#query / update，而非 StatementHandler#prepare：
 * 前者能拿到 MappedStatement，且对嵌套查询、级联、分页插件的兼容更好。
 */
@Intercepts(
    Signature(type = Executor::class, method = "query",
        args = [MappedStatement::class, Any::class, RowBounds::class, ResultHandler::class]),
    Signature(type = Executor::class, method = "update",
        args = [MappedStatement::class, Any::class]),
)
class TenantInterceptor(
    private val enforcedSchemas: Set<String>,
    private val excludedTables: Set<String>,
) : Interceptor {

    override fun intercept(invocation: Invocation): Any? {
        val ctx = UserContextHolder.get() ?: return invocation.proceed()
        if (ctx.tenantId == null) return invocation.proceed()      // 超管

        val ms = invocation.args[0] as MappedStatement
        val param = invocation.args[1]
        val boundSql = ms.getBoundSql(param)
        val originalSql = boundSql.sql

        if (!needsTenantRewrite(originalSql)) return invocation.proceed()

        val newSql = CCJSqlParserUtil.parse(originalSql).let { stmt ->
            when (stmt) {
                is Select -> rewriteSelect(stmt, ctx)
                is Update -> rewriteUpdate(stmt, ctx)
                else -> throw IllegalStateException("不支持的 SQL 类型：${stmt.javaClass.simpleName} -> $originalSql")
            }
        }

        val newBoundSql = BoundSql(
            ms.configuration, newSql,
            boundSql.parameterMappings, boundSql.parameterObject
        )
        boundSql.additionalParameters.forEach { (k, v) -> newBoundSql.setAdditionalParameter(k, v) }

        val newMs = copyMappedStatement(ms, newBoundSql)
        invocation.args[0] = newMs
        return invocation.proceed()
    }

    private fun needsTenantRewrite(sql: String): Boolean {
        val normalized = sql.lowercase()
        return enforcedSchemas.any { normalized.contains("$it.") } &&
               excludedTables.none { normalized.contains(it.lowercase()) }
    }

    private fun rewriteSelect(select: Select, ctx: com.agri.common.security.context.UserContext): String {
        val body = select.selectBody
        if (body !is PlainSelect) return select.toString()   // UNION 等复杂场景另行处理
        val alias = resolveAlias(body)
        if (hasTenantCondition(body.where, alias)) return select.toString()

        val condition = EqualsTo().apply {
            leftExpression  = buildColumn(alias, "tenant_id")
            rightExpression = LongValue(ctx.tenantId)
        }
        body.where = body.where?.let { AndExpression(it, condition) } ?: condition
        return select.toString()
    }

    private fun rewriteUpdate(update: Update, ctx: com.agri.common.security.context.UserContext): String {
        update.where = update.where?.let {
            AndExpression(it, EqualsTo().apply {
                leftExpression  = buildColumn(null, "tenant_id")
                rightExpression = LongValue(ctx.tenantId)
            })
        } ?: EqualsTo().apply {
            leftExpression  = buildColumn(null, "tenant_id")
            rightExpression = LongValue(ctx.tenantId)
        }
        return update.toString()
    }

    // 省略：resolveAlias / hasTenantCondition / buildColumn / copyMappedStatement 的实现
    // 要点：从 PlainSelect.fromItem 取表名与别名；无别名时用表名本身作为限定符

    override fun plugin(target: Any) = Plugin.wrap(target, this)
    override fun setProperties(properties: Properties) {}
}
```

### 4.5 数据权限拦截器（按 `sys.data_object` 注册信息改写）

```kotlin
package com.agri.common.mybatis.interceptor

import com.agri.common.security.context.*
import net.sf.jsqlparser.expression.operators.conditional.AndExpression
import net.sf.jsqlparser.parser.CCJSqlParserUtil
import net.sf.jsqlparser.statement.select.PlainSelect
import net.sf.jsqlparser.statement.select.Select
import org.apache.ibatis.mapping.BoundSql
import org.apache.ibatis.mapping.MappedStatement
import org.apache.ibatis.plugin.*

/**
 * 数据权限拦截器：在租户隔离之后追加数据范围条件。
 *
 * GLOBAL        → 不追加（仅超管）
 * TENANT_ALL    → 不追加（租户条件已由 TenantInterceptor 保证）
 * ORG_TREE      → alias.org_id IN (:orgTreeIds)
 * ORG_SELF      → alias.org_id = :orgId
 * MEMBER_TEAM   → (alias.created_member_id = :memberId OR alias.org_id IN (:orgTreeIds))
 * MEMBER_SELF   → alias.created_member_id = :memberId
 * CUSTOM_SQL    → 直接拼接 sys.data_scope_policy.scope_expression 中的 where 片段
 * DENY_ALL      → 抛出 AccessDeniedException
 *
 * 参数通过 MyBatis 的 additionalParameter 注入，避免与业务参数命名冲突。
 */
@Intercepts(
    Signature(type = Executor::class, method = "query",
        args = [MappedStatement::class, Any::class, RowBounds::class, ResultHandler::class]),
)
class DataScopeInterceptor(
    private val registry: DataObjectRegistry,   // 缓存 sys.data_object，5 分钟刷新
    private val defaultScope: ScopeType,
) : Interceptor {

    override fun intercept(invocation: Invocation): Any? {
        val ctx = UserContextHolder.get()
            ?: throw PermissionDeniedException("缺失权限上下文，拒绝执行查询（安全默认：拒绝）")

        val ms = invocation.args[0] as MappedStatement
        val boundSql = ms.getBoundSql(invocation.args[1])

        // 找出该 SQL 命中的受保护对象
        val objects = registry.match(boundSql.sql)
        if (objects.isEmpty()) return invocation.proceed()

        var sql = boundSql.sql
        val extraParams = mutableMapOf<String, Any?>()

        objects.forEach { obj ->
            val rule = ctx.scopeOf(obj.code)
            if (rule.scopeType == ScopeType.DENY_ALL)
                throw PermissionDeniedException("数据权限策略拒绝访问 ${obj.code}")

            if (rule.scopeType == ScopeType.GLOBAL || rule.scopeType == ScopeType.TENANT_ALL) return@forEach

            val alias = extractAlias(sql, obj.tableName)
            val (fragment, params) = buildFragment(alias, obj, rule, ctx)
            if (fragment.isBlank()) return@forEach

            val stmt = CCJSqlParserUtil.parse(sql)
            if (stmt is Select && stmt.selectBody is PlainSelect) {
                val body = stmt.selectBody as PlainSelect
                val parsed = CCJSqlParserUtil.parseCondExpression(fragment)
                body.where = body.where?.let { AndExpression(it, parsed) } ?: parsed
                sql = stmt.toString()
            }
            extraParams.putAll(params)
        }

        if (sql == boundSql.sql) return invocation.proceed()

        val newBoundSql = BoundSql(ms.configuration, sql,
            boundSql.parameterMappings, boundSql.parameterObject)
        boundSql.additionalParameters.forEach { (k, v) -> newBoundSql.setAdditionalParameter(k, v) }
        extraParams.forEach { (k, v) -> newBoundSql.setAdditionalParameter(k, v) }

        invocation.args[0] = copyMappedStatement(ms, newBoundSql)
        return invocation.proceed()
    }

    private fun buildFragment(
        alias: String?, obj: DataObjectMeta, rule: DataScopeRule, ctx: UserContext,
    ): Pair<String, Map<String, Any?>> = when (rule.scopeType) {
        ScopeType.ORG_SELF ->
            "${col(alias, obj.orgColumn!!)} = #{__orgId}" to mapOf("__orgId" to ctx.orgId)
        ScopeType.ORG_TREE ->
            "${col(alias, obj.orgColumn!!)} IN (__orgTreeIds)" to emptyMap()   // 展开为字面量，避免 IN #{list} 的坑
        ScopeType.MEMBER_SELF ->
            "${col(alias, obj.ownerMemberColumn!!)} = #{__memberId}" to mapOf("__memberId" to ctx.memberId)
        ScopeType.MEMBER_TEAM ->
            "(${col(alias, obj.ownerMemberColumn!!)} = #{__memberId} OR ${col(alias, obj.orgColumn!!)} IN (__orgTreeIds))" to
                mapOf("__memberId" to ctx.memberId)
        ScopeType.CUSTOM_SQL -> rule.expression!! to rule.params
        else -> "" to emptyMap()
    }.let { (frag, params) ->
        // ORG_TREE 展开为字面量 IN 列表（成员组织数通常 < 100，安全且避免 MyBatis foreach 复杂度）
        frag.replace("__orgTreeIds", ctx.orgTreeIds.joinToString(",", "(", ")")) to params
    }

    private fun col(alias: String?, column: String) = alias?.let { "$it.$column" } ?: column

    override fun plugin(target: Any) = Plugin.wrap(target, this)
    override fun setProperties(properties: Properties) {}
}
```

### 4.6 鉴权 WebFilter（注解 + 路径匹配双保险）

```kotlin
package com.agri.common.security.web

import com.agri.common.core.ApiResponse
import com.agri.common.security.context.UserContextHolder
import com.agri.common.security.spi.PermissionMatcher
import org.springframework.boot.autoconfigure.condition.ConditionalOnClass
import org.springframework.core.annotation.Order
import org.springframework.http.HttpStatus
import org.springframework.http.MediaType
import org.springframework.security.core.annotation.AuthenticationPrincipal
import org.springframework.stereotype.Component
import org.springframework.web.server.ServerWebExchange
import org.springframework.web.server.WebFilter
import org.springframework.web.server.WebFilterChain
import reactor.core.publisher.Mono

/**
 * 全局鉴权过滤器：路径 → 权限码 → 校验。
 *
 * 设计要点：
 *  1. 「未登记的 API」默认拒绝（白名单除外），防止新增接口忘记配权限就裸奔；
 *  2. 超管与租户管理员短路放行（见 UserContext.hasPermission）；
 *  3. 上下文写入 Reactor Context + ThreadLocal，供协程与 MyBatis 拦截器使用。
 */
@Component
@Order(-100)
class PermissionWebFilter(
    private val matcher: PermissionMatcher,     // 缓存 API 模式 → permissionCode 的匹配器（Trie/Ant）
    @Value("\${agri.security.permit-all:}") private val permitAll: List<String>,
) : WebFilter {

    private val antPathMatcher = org.springframework.util.AntPathMatcher()

    override fun filter(exchange: ServerWebExchange, chain: WebFilterChain): Mono<Void> {
        val path = exchange.request.path.value()
        val method = exchange.request.method?.name() ?: "GET"

        if (permitAll.any { antPathMatcher.match(it, path) }) return chain.filter(exchange)

        val ctx = exchange.getAttribute<UserContext>(CTX_KEY)
            ?: return denied(exchange, "未认证")

        val code = matcher.match(method, path)
        if (code == null) return denied(exchange, "接口未登记权限，拒绝访问")
        if (!ctx.hasPermission(code)) return denied(exchange, "无权限：$code")

        UserContextHolder.set(ctx)
        return chain.filter(exchange)
            .contextWrite { it.put(CTX_KEY, ctx) }
            .doFinally { UserContextHolder.clear() }
    }

    private fun denied(exchange: ServerWebExchange, msg: String): Mono<Void> {
        val resp = exchange.response
        resp.statusCode = HttpStatus.FORBIDDEN
        resp.headers.contentType = MediaType.APPLICATION_JSON
        val body = MAPPER.writeValueAsBytes(ApiResponse.fail(403, msg))
        return resp.writeWith(Mono.just(resp.bufferFactory().wrap(body)))
    }

    companion object {
        const val CTX_KEY = "AGRI_USER_CONTEXT"
        private val MAPPER = com.fasterxml.jackson.databind.ObjectMapper()
            .registerModule(com.fasterxml.jackson.module.kotlin.KotlinModule.Builder().build())
    }
}
}
```

### 4.7 Repository 实现：调度器卸载的实际落点

```kotlin
package com.agri.trade.infrastructure.persistence.repository

import com.agri.common.security.context.withJdbcContext
import com.agri.trade.domain.model.order.TradeOrder
import com.agri.trade.domain.repository.TradeOrderRepository
import com.agri.trade.infrastructure.persistence.mapper.TradeOrderMapper
import org.springframework.beans.factory.annotation.Value
import org.springframework.stereotype.Repository

@Repository
class TradeOrderRepositoryImpl(
    private val mapper: TradeOrderMapper,
    @Value("\${agri.jdbc.concurrency}") private val concurrency: Int,
) : TradeOrderRepository {

    /**
     * 关键点：MyBatis 是阻塞的，这里统一卸载到与连接池等宽的 IO 调度器，
     * 同时把 UserContext 刷进 IO 线程的 ThreadLocal，让拦截器能读到。
     * 业务代码（application/domain）完全感知不到这一层。
     */
    override suspend fun findById(id: Long): TradeOrder? = withJdbc {
        mapper.selectById(id)?.toDomain()
    }

    override suspend fun save(order: TradeOrder): TradeOrder = withJdbc {
        val po = order.toPO()
        if (po.id == null) mapper.insert(po) else mapper.update(po)
        po.toDomain()
    }

    override suspend fun page(query: OrderQuery): Page<TradeOrder> = withJdbc {
        // 租户隔离与数据范围已由拦截器注入，此处无需手写 tenant_id 条件
        val total = mapper.count(query)
        val rows  = mapper.selectPage(query)
        Page(rows.map { it.toDomain() }, total)
    }

    private suspend fun <T> withJdbc(block: suspend () -> T): T {
        val ctx = currentUserContext()
            ?: error("缺失 UserContext，拒绝执行持久层操作")
        return withJdbcContext(ctx, concurrency, block)
    }
}

/**
 * 从协程上下文读取 UserContext。
 * coRouter / mono { } 会把 Reactor Context 包装成 ReactorContext 元素挂在协程上下文上，
 * 因此先查自定义 Element，再回落到 ReactorContext 里由 Filter 写入的对象。
 * 取不到一律返回 null，由调用方抛错 —— 绝不静默放行。
 */
suspend fun currentUserContext(): UserContext? {
    val cc = currentCoroutineContext()
    cc[UserContextElement]?.let { return it.context }
    val reactorCtx = cc[ReactorContext]?.context ?: return null
    return reactorCtx.getOrDefault<Any>(PermissionWebFilter.CTX_KEY) as? UserContext
}
```

```kotlin
package com.agri.common.security.sync

import org.springframework.boot.context.event.ApplicationReadyEvent
import org.springframework.context.event.EventListener
import org.springframework.stereotype.Component
import org.springframework.transaction.annotation.Transactional

/**
 * 应用启动时把 permission.yml 同步到 sys.permission。
 *
 * 语义（重要）：
 *  - 按 (app_id, code) 做 upsert：更新 name/type/pattern/sort，不动 id（保证 role_permission 外键不失效）；
 *  - 标记 builtin=true，租户不可增删改；
 *  - 只停用（status=0）而非删除「库中已有但 yml 中已移除」的权限，避免历史授权数据断裂；
 *  - 新增权限对「租户管理员」自动生效（因为管理员角色是短路放行，不落 role_permission）。
 */
@Component
class PermissionSynchronizer(
    private val loader: PermissionYamlLoader,
    private val repository: PermissionRepository,
    private val eventPublisher: DomainEventPublisher,
) {
    @EventListener(ApplicationReadyEvent::class)
    @Transactional
    fun sync() {
        val decl = loader.load()                 // 解析 permission.yml
        val appId = repository.ensureApp(decl.app.code, decl.app.name)

        val declared = decl.flatten()            // 树 → 平铺，带父子关系
        declared.forEach { p ->
            repository.upsert(appId, p.parentCode, p)
        }

        val declaredCodes = declared.map { it.code }.toSet()
        val removed = repository.markDeprecated(appId, declaredCodes)
        if (removed.isNotEmpty()) {
            log.warn("以下权限已从代码清单移除，已停用但未删除（请确认是否清理历史授权）：$removed")
        }

        // 权限元数据变更 → 广播，各节点刷新本地缓存与 Redis 权限快照
        eventPublisher.publish(AppPermissionPublishedEvent(appId, declaredCodes))
        log.info("权限同步完成：app={}, 共 {} 条", decl.app.code, declared.size)
    }
}
```

### 4.9 租户初始化（满足"新建租户自动创建管理员角色"）

```kotlin
package com.agri.upms.domain.service

import com.agri.upms.domain.event.TenantCreatedEvent
import org.springframework.stereotype.Service
import org.springframework.transaction.annotation.Transactional

/**
 * 租户创建：落库 + 按类型模板建组织树 + 按类型开通应用 + 建管理员角色。
 * 全过程在一个事务内，失败整体回滚，不留半成品租户。
 */
@Service
class TenantFactory(
    private val tenantRepository: TenantRepository,
    private val orgRepository: OrgRepository,
    private val roleRepository: RoleRepository,
    private val permissionRepository: PermissionRepository,
    private val scopeBindingRepository: DataScopeBindingRepository,
    private val eventPublisher: DomainEventPublisher,
) {
    @Transactional
    fun create(cmd: CreateTenantCommand): Tenant {
        val type = tenantTypeRepository.require(cmd.tenantTypeCode)

        // 1. 落租户
        val tenant = Tenant.create(cmd, type).let(tenantRepository::save)

        // 2. 按租户类型的 org_levels 模板生成默认组织树
        OrgTreeTemplate.from(type.orgLevels).build(tenant.id).forEach(orgRepository::save)

        // 3. 按租户类型的可用应用，逐个创建管理员角色
        type.availableAppIds.forEach { appId ->
            val role = Role.tenantAdmin(tenantId = tenant.id, appId = appId)
            roleRepository.save(role)
            // 管理员角色不落 role_permission：鉴权时 isTenantAdmin 短路放行，
            // 这样应用后续新增权限会自动生效，无需补授权任务。
            scopeBindingRepository.bindDefaultTenantScope(role.id, appId)
        }

        eventPublisher.publish(TenantCreatedEvent(tenant.id, type.code))
        return tenant
    }
}
```

```bash
#   → 返回新令牌，且 Redis 中应出现 auth:perm:{memberId}:{appId}
```

## 六、需实测验证的风险点（不要假定）

| # | 风险 | 验证方式 | 兜底方案 |
|---|---|---|---|
| 1 | `mybatis-spring-boot-starter` 与 Spring Boot 4.1.1 的兼容性 | 起服务看是否报 `NoClassDefFoundError` / Bean 创建失败 | 排除 `MybatisAutoConfiguration`，用 4.3 节的手动 `SqlSessionFactoryBean` |
| 2 | Boot 4 默认 Jackson 版本（2.x / 3.x）导致的 Kotlin 模块不匹配 | 看 `jackson-module-kotlin` 是否被 BOM 正确管理 | 移除显式版本，完全交给 Boot BOM |
| 3 | Spring Security 7 的 `SecurityWebFilterChain` API 变化 | 起服务看过滤器链是否生效 | 改为自研 `WebFilter`（4.6 已给出不依赖 Security API 的版本） |
| 4 | `spring-cloud-starter-gateway-server-webflux` 的 artifact 名 | 构建期即可发现 | 老版本名是 `spring-cloud-starter-gateway` |
| 5 | JSqlParser 对复杂 SQL（CTE、窗口函数、UNION）的改写 | 单元测试覆盖真实 SQL | 解析失败时降级为「不改写 + 打 ERROR 告警」，由 RLS 兜底 |
| 6 | 协程 + ThreadLocal 在异常/取消路径下的清理 | 压测后检查是否有上下文串号 | `withJdbcContext` 已用 `finally` 兜底；再加一个监控指标统计 ThreadLocal 残留 |
